# Arsip Dokumentasi KOPASUS SIMAK Institut STIAMI

Struktur folder ini dirancang agar setiap generasi pengurus baru dapat mendokumentasikan kegiatan kaderisasi KOPASUS secara rapi dan berkelanjutan:

## Format Penamaan Folder:
- `archives/kopasus/[TAHUN]-batch-[NOMOR_BATCH]/`
  - `day-1/` : Pembekalan, Screening Integritas, Pembukaan
  - `day-2/` : Diklat Lapangan, Simulasi Investigasi, Api Unggun
  - `day-3/` : Jurit Malam, Sumpah Kader, Pembagian PDH & NIA

Contoh:
- `2024-batch-14/`
- `2025-batch-15/`
- `2026-batch-16/` (Generasi Saat Ini)
- `2027-batch-17/` (Generasi Mendatang)
